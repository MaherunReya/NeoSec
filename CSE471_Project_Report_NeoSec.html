1. System Request

Business need:

NeoSec addresses the critical need for a unified, user-friendly platform that combines VPN management and firewall protection in a single, accessible solution. Currently, users struggle with fragmented security tools that require technical expertise to configure and maintain. Small businesses, remote workers, and individuals need an integrated system that provides enterprise-grade network security without the complexity of traditional solutions. NeoSec bridges this gap by offering a web-based management interface that simplifies VPN configuration, firewall rule management, and threat protection, making advanced network security accessible to non-technical users while maintaining the power and flexibility required by IT professionals.

Business requirements:

NeoSec must deliver a comprehensive security management platform with the following core capabilities:

  • User Management & Authentication: Secure registration, login, and role-based access control (admin, operator, viewer) with JWT-based authentication, session management, and multi-factor authentication support.
  • VPN Management: Complete lifecycle management of VPN configurations (OpenVPN and WireGuard), including creation, editing, activation, and automatic synchronization with desktop clients. Support for profile-based VPN switching and scheduling.
  • Firewall Rule Management: Intuitive web interface for creating, editing, and deleting firewall rules with support for IP addresses, ports, protocols (TCP/UDP/BOTH), and actions (ACCEPT/REJECT/DROP). Rules must be automatically synchronized to desktop clients for kernel-level enforcement.
  • Profile Management: Centralized system for creating and managing security profiles that combine VPN configurations, firewall rules, DNS settings, and access controls. Profiles should support scheduling, versioning, and audit logging.
  • Threat Protection: Automated threat blocker that integrates with AbuseIPDB and other threat intelligence sources to automatically update blocklists. Real-time threat detection and blocking with geolocation-based rules.
  • Desktop Client Integration: Linux desktop application that securely communicates with the server, automatically applies configurations, and enforces firewall rules at the kernel level using iptables/nftables.
  • Monitoring & Reporting: Comprehensive dashboard showing VPN status, threat statistics, activity logs, and system health metrics. Real-time notifications for critical events.
  • Hierarchy & Access Control: Organizational structure (Organization → Team → User) with scoped permissions, delegation, and access matrix for enterprise environments.
  • File Scanning: Integration with VirusTotal API for scanning files, URLs, and IP addresses for malicious content.
  • Subscription Management: Support for free and paid subscription tiers with Stripe integration for payment processing.

Business value:

NeoSec creates significant value for multiple stakeholders by consolidating network security management into a single, cost-effective platform. For individual users and small businesses, it eliminates the need for expensive enterprise security solutions while providing professional-grade protection. The platform reduces operational costs by automating threat detection and firewall rule updates, minimizing the need for dedicated IT staff. For enterprises, the hierarchical access control and audit logging features ensure compliance and governance while maintaining security. The subscription model provides predictable revenue streams, and the scalable architecture supports growth from individual users to large organizations. By simplifying complex security operations, NeoSec reduces the barrier to entry for effective network security, potentially preventing costly security breaches and data loss incidents.

Special issues or constraints:

NeoSec faces several critical challenges that must be addressed:

  • Security & Privacy: The platform handles sensitive network configurations, user credentials, and threat intelligence data. Robust encryption, secure authentication, and compliance with data protection regulations (GDPR, etc.) are essential. All communications between web client, server, and desktop client must be encrypted.
  • Cross-Platform Compatibility: The desktop application must work exclusively on Linux systems, requiring careful handling of Linux-specific networking tools (iptables, nftables, NetworkManager). The web interface must be responsive and work across all modern browsers.
  • Real-Time Synchronization: Desktop clients must stay synchronized with server configurations without manual intervention. This requires reliable background processes, error handling, and rollback mechanisms when updates fail.
  • Performance & Scalability: The system must handle thousands of concurrent users, process threat intelligence updates efficiently, and maintain low latency for dashboard updates and rule synchronization.
  • Network Privileges: Desktop firewall enforcement requires elevated privileges (sudo/root), which presents security and usability challenges. The application must handle privilege escalation securely and gracefully.
  • API Rate Limits: Integration with external services (AbuseIPDB, VirusTotal, IP geolocation APIs) is subject to rate limits and API costs, requiring efficient caching and usage optimization.
  • Desktop Application Deployment: Linux desktop applications require distribution through package managers or direct downloads, adding complexity to deployment and updates compared to web-only solutions.

2. Functional Requirements

Module 1: User Management & Core Features

[Saadat-1] Admin Panel & User Management, Dashboard & Status Monitoring

  • The system allows users to sign up and log in securely with email and password authentication.
  • Dashboard is the main screen every user sees, displaying personal status including:
    • VPN connection status ("Is my VPN connected?")
    • Threat blocking statistics ("How many threats has my client blocked?")
    • System health metrics
    • Recent activity logs
  • Admin Panel is a separate, protected section only accessible to administrators, providing:
    • View and edit all user accounts
    • Monitor application health and statistics
    • Manage user roles and permissions
    • Review audit logs and system events
    • Approve or reject user registrations

[Rayhan-2] Automation, Scheduling & Secure Server Communication

  • The desktop software communicates with the server securely via JWT authentication tokens.
  • Periodically fetches updates from the server without manual interaction.
  • Automatically applies new rules based on the configuration.
  • Automatically starts the application on system boot.
  • Users can manually sync the client with the server on demand.
  • If new profile validation fails, the system rolls back to the previous working configuration.
  • If the server is unreachable, the client uses the last updated configuration (offline mode).

[Fariha-3] Authentication (JWT-based) & User Roles

  • Role-Based Access Control: Different user roles (admin, operator, viewer) define permissions for system features.
  • Session Protection: Users can stay signed in with secure session management. Sessions refresh automatically and logout safely when needed.
  • Core Operations: Sign in and sign out have built-in protection with JWT token validation.
  • Validation Criteria: Only authorized users can access protected parts, and sessions refresh without requiring re-login.
  • Secure Login System: Users authenticate through JWT tokens with short-lived access tokens and refresh token support.

[Maherun-4] Profile Management

  • Central system for creating, editing, and managing user security profiles on the website.
  • Each profile defines VPN configuration, firewall rules, DNS settings, and access controls.
  • Users can easily organize and apply different security setups for specific use cases (e.g., Work VPN, Public WiFi Mode).
  • Profiles are safely stored in the database, encrypted, and retrievable only by authorized users.
  • Ensures data consistency and accountability through audit logging — every edit or change is recorded with timestamps and user info.
  • Profiles can be linked to scheduling features to automatically activate at specific times or under specific conditions.
  • Designed for scalability and reliability, allowing organizations to manage multiple users and profiles efficiently.

Module 2: Task and Project Organization

[Saadat-1] Firewall Rule Management

  • Simple web page with a table and forms for managing firewall rules.
  • Users can easily add, edit, or delete their own custom firewall rules.
  • Each rule has clear options:
    • Action: Allow (ACCEPT), Deny (REJECT), or Drop (DROP)
    • Criteria: Specific IP address, port number, or traffic direction
    • Protocol: TCP, UDP, or BOTH
  • Every rule created by a user is saved to PostgreSQL database.
  • Desktop app downloads these rules from the database to know what to block or allow.

[Rayhan-2] Firewall via iptables/nftables

  • Loads firewall rules from the remote server and enforces them on the fly.
  • Done via iptables/nftables to enforce rules at kernel level.
  • Runs via elevated privilege using a daemon or sudo permission.
  • Rules are updated automatically on server synchronization.
  • Cronjob-based firewall rules enforcement as per configuration.
  • Event-based firewall rules enforcement (e.g., certain WiFi networks connected).

[Fariha-3] VPN Configuration Management

  • VPN Endpoint Setup: Easily manage VPN connections with preferred settings (OpenVPN and WireGuard).
  • Profile Linking: Attach VPN setup to security profiles for organized project control.
  • Validation & Versioning: Every configuration is checked for accuracy and can be cloned or restored at any time.
  • Task Assignment: Automatically send VPN setup tasks to specific devices or users.
  • Live Status Updates: Real-time progress updates and results as VPN configs are applied.

[Maherun-4] Feature-2: Profile Sharing via Encrypted Link

  • Allows users to share security profiles (VPN/firewall configurations) with others through secure, encrypted links.
  • Makes collaboration easier while keeping sensitive data protected. No raw credentials or configs are ever exposed.
  • Recipients can view or import the shared profile depending on the permissions set by the sender.
  • Senders can add a password to the shared link for extra protection.
  • The system supports revoking a shared link at any time — immediately removing access for all recipients.
  • All link activity (views, imports, expirations) is tracked and logged for transparency and auditing.

Module 3: Dashboard and Notifications

[Saadat-1] Automatic Threat Blocker (from Malware/IP Blocklist Integration)

  • Set up an automated task on the server (a "cron job") that runs every night.
  • Automatically calls the AbuseIPDB API to download a fresh list of thousands of known dangerous IP addresses (hackers, malware, etc.).
  • The server saves this new list to the database, and all desktop clients automatically download it and add it to their local firewall rules, so they are always protected against the latest threats.

[Saadat-1] Scheduling and Notifications, Logs and Reporting

  • A logging system where desktop clients continuously send their activity (like VPN status or firewall blocks) to the web server, which stores everything in the PostgreSQL database.
  • Log Viewer: A "Log Viewer" page on the web app allows users and admins to search, filter (by date, IP, etc.), and download these logs to see what's happening or troubleshoot problems.
  • In-App Notifications: A notification system inside the dashboard. When the server detects a critical event (like a scheduled profile failing), it sends an alert to the web app, which appears as a pop-up or notification icon for the user.

[Rayhan-2] VPN Management

  • Connects, monitors, and terminates VPN connections (Wireguard, OpenVPN) as per rules using background process.
  • Rules update periodically without manual interaction.
  • VPN profiles switch automatically based on the latest rulesets.
  • Time-based rules enforcement via cronjobs.
  • Event-based rules enforcement (Connected to certain networks).
  • Terminates internet access / Keeps connection active based on rules if VPN server is unavailable.

[Rayhan-2] Geolocation based IP rules via 3rd party API

  • Fetches the geolocation of IP and blocks/allows as per user set rules.
  • Caches IP locations for a certain period to ensure low latency.
  • Other rules can be combined with geolocation rules to make the system more flexible. For example, users can set rules like: "allow all IP from Russia if the time is between 11:00 to 14:00 otherwise block it."
  • The Geolocation is fetched via external API.

[Fariha-3] External mail APIs to send instant email alerts

  • Event Monitoring: Instantly tracks issues like VPN errors, firewall problems, or expiring certificates.
  • Instant Email Alerts: Sends immediate notifications through trusted email services when critical errors occur.
  • Dedicated Notification Panel: Provides a central dashboard section for reviewing past alerts and detailed event logs.
  • Priority Control: Important alerts are sent first, while duplicates are filtered to avoid clutter.

[Fariha-3] Hierarchy

  • Structured Access: Establishes an Organization → Team → User hierarchy for clear role separation.
  • Scoped Permissions: Users can only manage profiles within their assigned teams.
  • Delegation System: Allows admins to assign managers who can review and approve changes in their scope.
  • Access Matrix & Logs: Admins can appoint managers to approve and oversee changes.
  • Secure Governance: Admins keep complete control while enforcing strict role boundaries.

[Maherun-4] Feature-3: External API based file scanning

  • Upload a file to scan using various antivirus products.
  • Use VirusTotal to scan for malicious signatures in user-provided files.
  • Scan URLs for threats.
  • Get IP address-based security reports using VirusTotal.
  • Automatically generates a scan report summary, showing how many antivirus engines flagged the file or link.
  • Protects user privacy; only hashes and metadata are sent to VirusTotal, not private or personal content.

[Maherun-4] Feature-4: Paid account and Payment

  • Enables users to upgrade to paid plans (e.g., Basic, Pro, Enterprise) for additional features and higher usage limits.
  • Provides a secure and integrated payment system directly on the website using Stripe.
  • Supports subscription management, billing history, and automatic plan enforcement.
